# 交付说明

## 快照范围

来源是 2026-11-06 K1 实际源码、组装结果与用户级 systemd 配置。原始采集包和详细对照保存在本地交付目录，不进入仓库。已将运行文件映射回业务源码或 K1 覆盖层，避免构建脚本装回较早文件。

此次不修改小车算法，不部署回 K1，不清除控制锁、不调整地图/点位/门限，也不启动任务。包含 STM32、底盘/雷达/ROS2、导航/建图/定位、语音、仪表本地/云端识别、网页及后端、地图和部署配置。工程整理仅调整构建输入、安装模板及目录绑定：语音模块可选恢复改用系统 adb 和正式运行目录，RGB 辅助输出改到 perception 运行目录，不依赖此前临时诊断路径。

排除现场实验脚本、测试目录、网页验证脚本、历史任务/日志/录音、数据库、缓存、备份、构建输出和 `node_modules`。现有 `tests/.gitkeep` 保留目录占位。第三方库的构建辅助文件不代表新增了现场测试代码。

模型和提示音通过资源包交付，仓库保存校验清单与导入器。资源包不含任务记录、录音或 API 密钥。外部 SDK/板厂系统依赖按固定清单准备。

## 回退原则

只在任务停止后更换部署目录；保留本机 `configs`、`state`、环境和密钥备份。不要将旧缓存/数据库当作源码装到新设备。组装和服务安装器拒绝覆盖已有运行目录/服务，升级应使用独立 checkout、备份和经过审核的切换步骤。

不把临时诊断脚本和逐轮修复记录发布为产品部署入口。部署和编译入口仅保留 K1；公用算法中保留历史注释/环境变量回退值，不表示需要另一台设备或其他板型部署。K1 服务环境显式配置本工程的实际路径。
